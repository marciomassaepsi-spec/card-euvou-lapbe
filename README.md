# #EuVou · I Simpósio LAPBE

Página para montar o story **#EuVou** do I Simpósio da Liga Acadêmica de Psicologia Baseada em Evidências (LAPBE), em 14 de novembro.

O participante escolhe uma foto, digita o nome e baixa a imagem pronta (1080×1920) para postar nos stories. No celular, o botão abre o menu de compartilhamento, com as opções "Salvar imagem" e postar direto no Instagram.

A imagem é montada no próprio aparelho de quem usa: nenhuma foto é enviada para servidor algum.

**Acesse:** https://marciomassaepsi-spec.github.io/card-euvou-lapbe/

## Arquivos

- `index.html` — a página inteira (o brasão está embutido no próprio arquivo)
- `og.jpg` — imagem de prévia quando o link é compartilhado
- `favicon.png`, `apple-touch-icon.png` — ícones da aba e da tela inicial do celular

## Como editar

Para mudar a data, os textos ou o @ do Instagram, edite o `index.html` direto no GitHub (ícone de lápis) e salve. O site atualiza sozinho em cerca de um minuto.
